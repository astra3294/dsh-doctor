# 恢复矩阵

| 故障 | 检测方式 | v0.1.0 动作 | 是否确认 | 是否重启 |
|---|---|---|---|---|
| `package.json` 无法解析 | JSON 解析器 | 从最近健康检查点恢复该文件 | 已证明文件损坏时无需确认 | 是 |
| `cordis.patch.yml` 无法解析 | YAML 解析器 | 从最近健康检查点恢复该文件 | 已证明文件损坏时无需确认 | 是 |
| settings 文档损坏 | YAML/JSON 解析器 | 从最近健康检查点恢复该文件 | 已证明文件损坏时无需确认 | 通常需要 |
| 依赖缺失或链接损坏 | 包解析与链接目标 | 运行 profile 的 `pnpm install`；除非明确允许，否则保持离线 | 是 | 是 |
| 第三方 Cordis 插件失败 | Loader 实时快照 | 在当前 profile patch 中追加 `disabled: true` | 是 | 是 |
| 救援链路或核心插件失败 | Loader 实时快照 | 拒绝自动禁用，提供人工处理指引 | 人工 | 是 |
| API Key 无效或缺失 | 模型/Agent 错误 | 引导模型设置；绝不读取或覆盖密钥 | 人工 | 否 |
| Harness 版本不受支持 | 版本比较 | 只读报告，不执行修改 | 不可用 | 不适用 |
| Host 无法连接 | Doctor RPC | 复制 `npx dsh-doctor recover --profile web` | 否 | 不适用 |

“已经恢复”只代表结构检查通过。真实模型请求会被单独询问；用户跳过时绝不会报告为验证通过。
